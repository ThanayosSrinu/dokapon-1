# Art credits

[Creative Commons CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
(public domain). It may be used in personal, educational and commercial
projects. Credit is not required, but this file keeps it anyway. Each pack's
original `License.txt` sits next to its files.

| `ui/` | Made from UI Pack - Pixel Adventure | The same tiles enlarged to 2x for panels and buttons |
